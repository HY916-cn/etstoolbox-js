## 产品功能

- 提供 `F1` 设置面板，用于管理得分比例、随机偏移、提交用时和自动流程。
- 调整听说题目的总分、完整度、准确度、流畅度与逐词分值。
- 每个单词独立计算命中概率和实际分值，由客户端按原生规则显示对应颜色。
- 将页面能够识别的参考内容发送至独立答案终端。
- 用户手动开始整套练习后，自动处理录音、停止录音和后续“下一步”。

## 使用方法

完整安装后按 `F1` 打开功能面板。“自动录音”和“自动下一步”是两个独立开关，同时启用时组成完整流程。第一次“开始”仍由用户手动点击，录音状态实际生效后才开始客户端要求的 2 秒计时。

启用“显示答案”后，可在同一行点击“打开答案终端”。页面没有直接提供参考内容时，完整版 DLL 会通过本机回环接口匹配 `%APPDATA%\ETS` 中已经下载的题目元数据；该过程不会联网查询答案。

## 开发指南

### 环境要求

- Node.js 20 或更高版本
- npm

### 安装依赖与测试

```bash
git clone https://github.com/HY916-cn/ETSToolbox-js.git
cd ETSToolbox-js
npm ci
npm test
```

### 生产构建

```bash
npm run build
```

构建结果：

```text

```

开发期间可使用监听构建：

```bash

```

提交前建议运行完整检查：

```bash

npm test
npm run build
git diff --check
```

## 实现说明

- 功能范围由客户端路由和页面结构共同判断；得分、提交用时和自动流程只处理已识别的听说练习。
- 提交前会同步更新 `/m/audio/sync-v2` 中的总分、实际分数、分项分数、完整度、准确度和流畅度。
- 文本朗读会在评测 XML 写盘和上传前同步写入总分、三项指标和逐词分值，确保接口记录和结果页面使用同一组数据。
- 基准百分比和随机偏移上限限制为 `0` 至 `100`。每道题独立随机，越界时重新生成；最终百分比和分数最多保留两位小数。
- 三项朗读指标通常生成互不相同的合法整数。合法范围不足时优先保证数值有效。
- 每个普通单词会独立生成“基准百分比 ± 随机偏移”作为命中概率，再生成实际分值。换行、角色名和标点保持原样，显示颜色由客户端原生阈值决定。
- 自动流程只识别 `.exam-action-bar` 中的录音、停止录音和下一步按钮。点击后会检查页面状态，未生效时按受控间隔重试。
- 答案提取器支持听说、单选、完形、填空、阅读、翻译、写作、口语参考表达和常见嵌套字段。只下发题干时，会请求本机 DLL 匹配已经下载的完整元数据。
