# ETSToolbox 前端

这是 ETSToolbox 的浏览器端脚本，用于 Windows 版 E听说客户端。

## 能做什么

- 按百分比调整听说题目的最终得分，可为每道题设置随机偏移上限。
- 文本朗读的准确度、流畅度、完整度使用互不相同的随机结果；每个单词以“基准百分比 ± 随机偏移”为命中概率独立赋分，颜色由客户端按最终分值原生渲染。
- 修改作业记录中的提交用时。
- 把听说、选择、填空、完形、阅读、翻译、写作等页面中能够识别的参考答案写入独立终端；页面未直接提供答案时，可匹配本机已经下载的题目元数据。
- 用户手动点击整套练习的“开始”后，自动开始录音、等待 2 秒、停止录音。
- 可单独开启“自动下一步”，持续推进到下一项操作或任务结束。

按 `F1` 打开设置面板。“自动录音”和“自动下一步”是两个独立开关，同时开启时组成完整自动流程。

## 适用范围

控分、作业提交用时和自动流程只在已识别的听说练习路由生效。答案抓取不限制题目类型；任何页面只要提供了能够识别的参考答案数据，就会输出到答案终端。

本项目只用于个人、本地、离线学习测试。请勿在学校、机构、正式考试、正式作业、共享设备或其他公共环境中使用，也不要用它影响真实成绩或他人数据。

## 安装与使用

普通用户应从维护仓库的 Release 下载完整 Windows 包，不需要单独构建此前端。

启用“显示答案”后，点击同一行出现的“打开答案终端”按钮。终端会在题目变化时刷新。首次开始整套练习仍由用户手动点击；自动流程不会绕过客户端的 2 秒录音冷却。

本机题库匹配依赖完整版 DLL 提供的回环接口。它只读取 `%APPDATA%\ETS` 中已经下载的 `content.json`/`content2.json`，不联网查询答案；单独替换前端文件无法启用该功能。

## 测试与构建

需要 Node.js 20 或更高版本。

```bash
git clone https://github.com/HY916-cn/ETSToolbox-js.git
cd ETSToolbox-js
npm ci
npm test
npm run build
```

生成文件：

## 技术说明

- 页面范围由听说路由白名单判断。
- 自动流程只识别 `.exam-action-bar` 中的 `btn-record`、`btn-stopRecord` 和“下一步”按钮。
- 录音状态实际出现后才开始 2 秒计时；点击后检查按钮状态是否变化，未变化时按受控间隔重试。
- 控分只处理听说练习。提交前会同步改写 `/m/audio/sync-v2` 中的 `score`、`real_score`、`score_detail.total_score`、准确度、流畅度和完整度；文本朗读还会在评测 XML 写入并上传前改写相同的总分、三项指标及逐词得分，使接口记录与结果页使用同一组数据。基准百分比和随机偏移上限均限制为 `0` 至 `100`，每道题独立随机；越界结果会重新生成。最终百分比和分数最多保留两位小数，并遵循客户端给出的分值步进。
- 文本朗读维度写入客户端的 0–5 原始字段，显示时换算为 0–100；通常生成三个互不相同的整数。偏移范围过小、在两位小数精度内不足三个合法值或偏移为 0 时，优先保证范围合法。
- 结果页的每个普通单词会先独立生成一次 `基准百分比 ± 随机偏移` 作为绿色概率，再独立抽样。命中后从 80–100 生成绿色得分；未命中时等概率选择橙色或红色，并分别从 60–79.99 或 0–59.99 生成得分。换行、角色名和标点保持原样；相同逻辑也会写入上传的评测 XML。
- 作业用时只处理 `m/homework/set-use-time`。
- 答案提取支持听说、单选、完形、填空、阅读、翻译、写作、口语参考表达及常见嵌套答案字段；选择题会同时显示选项字母和选项正文。实测 iframe 只下发题干时，脚本会提取题目特征并请求 DLL 在本机缓存中匹配完整元数据；客户端数据结构变化后可能需要适配。
- “打开答案终端”只请求 ETSToolbox 的本机回环接口；具体启动动作由 DLL 后端执行。
