# ETSToolbox 前端

这是 ETSToolbox 的浏览器端脚本，用于 Windows 版 E听说客户端中的听说练习页面。

## 能做什么

- 按百分比调整听说题目的最终得分，可为每道题设置随机偏移上限。
- 修改作业记录中的提交用时。
- 把当前题目的参考答案写入独立终端。
- 用户手动点击整套练习的“开始”后，自动开始录音、等待 2 秒、停止录音。
- 可单独开启“自动下一步”，持续推进到下一项操作或任务结束。

按 `F1` 打开设置面板。“自动录音”和“自动下一步”是两个独立开关，同时开启时组成完整自动流程。

## 适用范围

所有功能只在已识别的听说练习路由生效。读写、单词、配音、主页面和结果页面不会执行改分、改用时、答案输出或自动点击。

本项目只用于个人、本地、离线学习测试。请勿在学校、机构、正式考试、正式作业、共享设备或其他公共环境中使用，也不要用它影响真实成绩或他人数据。

## 安装与使用

普通用户应从维护仓库的 Release 下载完整 Windows 包，不需要单独构建此前端。

启用“显示答案”后，运行安装目录中的：

```text
C:\Program Files (x86)\ETS\etstoolbox\open-answer-console.cmd
```

终端会在题目变化时刷新。首次开始整套练习仍由用户手动点击；自动流程不会绕过客户端的 2 秒录音冷却。

## 测试与构建

需要 Node.js 20 或更高版本。

```bash
git clone https://github.com/HY916-cn/ETSToolbox-js.git
cd ETSToolbox-js
npm ci
npm test
npm run build
```

生成文件：

```text
prod/index.js
prod/index.iframe.js
css/index.css
```

开发监听构建：

```bash
npm run watch
```

## 技术说明

- 页面范围由听说路由白名单判断。
- 自动流程只识别 `.exam-action-bar` 中的 `btn-record`、`btn-stopRecord` 和“下一步”按钮。
- 录音状态实际出现后才开始 2 秒计时；点击后检查按钮状态是否变化，未变化时按受控间隔重试。
- 控分只处理 `/m/audio/sync-v2`。基准百分比和随机偏移上限均限制为 `0` 至 `100`，每道题独立随机；越界结果会重新生成。最终百分比和分数最多保留两位小数，并遵循客户端给出的分值步进。
- 作业用时只处理 `m/homework/set-use-time`。
- 答案提取支持选择、填空、口语参考表达和常见的嵌套答案字段；客户端数据结构变化后可能需要适配。
